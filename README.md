## 📌 About This Repository

Welcome to my **Database Management Systems (DBMS) Laboratory Repository**!

## 🎯 Objectives

The main objectives of these laboratory experiments are:

1. Understand fundamental concepts of relational database management systems.
2. Design Entity-Relationship diagrams and convert them into relational schemas.
3. Implement database integrity constraints using SQL.
4. Perform data retrieval and manipulation using SQL queries.
5. Understand joins, nested queries, aggregation, and query execution plans.
6. Create database views and recursive Common Table Expressions.
7. Implement stored procedures, triggers, and audit logging.
8. Apply database normalization techniques from 1NF to BCNF.
9. Understand transactions, ACID properties, and concurrency control.
10. Evaluate indexing strategies and optimize SQL query performance.

## 🚀 How to Run the Experiments

### Step 1 — Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/antrang0912-dotcom/DBMS-Experiments.git
```

Then navigate into the project directory:

```bash
cd DBMS-Experiments
```

Alternatively, download the repository using **Code → Download ZIP** on GitHub.

### Step 2 — Set Up the Database Environment

For MySQL-based experiments:

- Install MySQL Server 8.0 or later.
- Open MySQL Workbench or another compatible SQL client.
- Connect to your local MySQL server.

For Experiment 08:

- Install PostgreSQL.
- Open pgAdmin 4 or the PostgreSQL command-line interface.
- Use two database sessions for concurrency demonstrations.

### Step 3 — Execute the SQL Files

1. Open the required experiment folder.
2. Read its `README.md` for prerequisites.
3. Open the numbered SQL scripts in your database client.
4. Execute the scripts in the documented order.
5. Observe the results and compare them with the expected behavior.
