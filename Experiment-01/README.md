# Experiment 01 – ER Diagram Design

## Aim
To design an Entity-Relationship (ER) Diagram for an Indian E-Commerce Platform.

## Description
This experiment focuses on designing a conceptual database model for an e-commerce platform using an ER diagram.

The diagram includes entities such as:
- Customer
- Product
- Order
- Seller
- Category
- Payment
- Delivery
- Address

## Concepts Covered
- Entities and Attributes
- Primary Keys
- Composite and Multivalued Attributes
- Weak Entities
- Relationships and Cardinality
- Specialization
- Participation Constraints
